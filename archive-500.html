THE HONEST RULEBOOK

Chaos, with receipts.

Every racer starts with the same array. One synchronized round advances each active racer by one instrumented operation. Finished results are checked against the original values.

Rankings use operations: comparisons, main-array swaps/writes, and instrumented auxiliary work. This visualization counts selected operations; it is not elapsed time, CPU benchmarking, or a universal ranking.

500 contestants include independent algorithms and explicitly labeled pivot, gap, heap and radix variants. This is a runnable roster—not an implementation of every research algorithm in the earlier brainstorm. Source code is available for every racer.

Bogo, Bogobogo, Stooge and Slow can take absurd amounts of work. The budget stops them honestly: BUDGET STOP never means “sorted”. Networks use power-of-two sizes; integer sorts use values 1–99.

Every racer starts with the same array. One synchronized round advances each active racer by one instrumented operation. Finished results are checked against the original values.

Rankings use operations: comparisons, main-array swaps/writes, and instrumented auxiliary work. This visualization counts selected operations; it is not elapsed time, CPU benchmarking, or a universal ranking.

These are 100 custom hybrid recipes: ten grouping rules × ten established local sorting methods, followed by balanced merging. Every combination is unique. They share components and are not claimed to be 100 newly discovered algorithms. Names are fictional contestant names, not historical Lucas quotes.

Grouping, numeric routing, comparisons, auxiliary appends, and array writes are instrumented. JavaScript bookkeeping is not fully counted. The budget stops unfinished racers honestly: BUDGET STOP never means “sorted”. Race inputs are integers 1–99. Rankings depend on the input and this counting model.
